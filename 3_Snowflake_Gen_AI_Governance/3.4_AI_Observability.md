## TruLens SDK for AI Observability

TruLens is an **open-source SDK** (acquired by Snowflake) for evaluating and monitoring AI/LLM application quality. It integrates natively with Snowflake.

### Key Concepts

| Concept | Description |
|---------|-------------|
| **Feedback Functions** | Metrics that score LLM outputs (relevance, groundedness, etc.) |
| **Tracing** | End-to-end logging of every step in an AI pipeline |
| **Evaluation** | Automated quality assessment of RAG, agents, chatbots |
| **Dashboard** | Visual monitoring of AI application health |

### Core Evaluation Metrics

| Metric | What It Measures |
|--------|-----------------|
| **Answer Relevance** | Does the answer address the question? |
| **Context Relevance** | Is the retrieved context relevant to the question? |
| **Groundedness** | Is the answer supported by the provided context? |
| **Coherence** | Is the answer logically consistent? |
| **Harmfulness** | Does the response contain harmful content? |
| **Stereotypes** | Does the response contain stereotypical content? |

### RAG Triad (Exam-Critical)

```
                    GROUNDEDNESS
                   (Answer ↔ Context)
                        ▲
                       / \
                      /   \
                     /     \
    CONTEXT RELEVANCE      ANSWER RELEVANCE
    (Context ↔ Question)   (Answer ↔ Question)
```

The **RAG Triad** evaluates three relationships:
1. **Context Relevance**: Is the retrieved context relevant to the user's question?
2. **Groundedness**: Is the generated answer grounded in (supported by) the retrieved context?
3. **Answer Relevance**: Does the generated answer actually address the user's question?

## TruLens with Snowflake

```python
from trulens.core import TruSession
from trulens.connectors.snowflake import SnowflakeConnector

# Connect TruLens to Snowflake (logs stored in Snowflake tables)
connector = SnowflakeConnector(snowpark_session=session)
tru_session = TruSession(connector=connector)

# Define feedback functions
from trulens.providers.cortex import Cortex

provider = Cortex(snowpark_session=session, model="llama3.1-70b")
f_groundedness = provider.groundedness_measure_with_cot_reasons
f_relevance = provider.relevance

# Wrap your RAG app
from trulens.apps.custom import TruCustomApp

tru_app = TruCustomApp(
    app=my_rag_app,
    app_name="Customer Support Bot",
    feedbacks=[f_groundedness, f_relevance]
)

# Run with logging
with tru_app as recording:
    response = my_rag_app.query("What is our refund policy?")
```

## Event Tables and Tracing

Snowflake event tables capture telemetry from AI applications:

```sql
-- Create event table
CREATE EVENT TABLE my_ai_events;

-- Set as account event table
ALTER ACCOUNT SET EVENT_TABLE = 'my_db.my_schema.my_ai_events';

-- Query AI function traces
SELECT * FROM my_ai_events
WHERE RESOURCE_ATTRIBUTES['snow.executable.type'] = 'AI_FUNCTION'
ORDER BY TIMESTAMP DESC;
```

### What Gets Logged

| Event Type | Information |
|-----------|-------------|
| AI Function calls | Model, tokens, latency, status |
| Cortex Search queries | Query text, results count, latency |
| Agent invocations | Tools called, reasoning steps |
| Custom application events | Whatever you log via Python SDK |

## Cortex Agent Evaluations (GPA Framework)

| Metric | What It Measures |
|--------|-----------------|
| **Tool selection accuracy** | Did agent pick the right tools? |
| **Tool execution accuracy** | Were tool inputs/outputs correct? |
| **Answer correctness** | Does final answer match ground truth? |
| **Logical consistency** | Is reasoning internally consistent? |

## Cortex Analyst Evaluations

Measures SQL generation accuracy against verified queries:

1. **Selected VQRs are TEMPORARILY REMOVED** from the semantic view during evaluation
2. Cortex Analyst must generate SQL **without that specific VQR's guidance**
3. Both the generated SQL results and VQR ground truth are compared
4. Reports `sql_correctness` metric (LLM-as-judge evaluates result equivalence)
5. Regression metrics track queries that previously worked but now fail

**Why temporary removal?** This tests whether the model can handle those questions independently. If it can only answer correctly when guided by the VQR, the model needs improvement.

Uses LLM-as-judge technique (AI_COMPLETE evaluates SQL output equivalence).

## Monitoring Best Practices

1. **Set up TruLens** for ongoing quality monitoring
2. **Use event tables** for operational logging
3. **Track the RAG Triad** for any RAG application
4. **Run Cortex Analyst evaluations** before deploying semantic views
5. **Monitor cost views** alongside quality metrics
6. **Alert on quality degradation** (groundedness drops, relevance drops)

## Exam Tips

1. **RAG Triad** = Context Relevance + Groundedness + Answer Relevance
2. **TruLens** is the observability SDK for AI apps in Snowflake
3. **Groundedness** = is the answer supported by context (not hallucinated)
4. **Event tables** capture AI function telemetry
5. **Agent evaluations** use GPA framework (Goal-Plan-Action)
6. **Analyst evaluations** use `sql_correctness` metric (LLM-as-judge)
7. **TruLens stores logs in Snowflake** via SnowflakeConnector
8. **Feedback functions** are the scoring mechanisms in TruLens
