# 3.3 Cost Management and Monitoring

> **Exam Domain:** 3.0 — Snowflake Gen AI Governance (29%)  
> **Exam Objective:** Track, monitor, and control Cortex AI spending

---

## Usage History Views

### CORTEX_FUNCTIONS_USAGE_HISTORY

Per-call credit and token consumption:

```sql
SELECT * FROM SNOWFLAKE.ACCOUNT_USAGE.CORTEX_FUNCTIONS_USAGE_HISTORY
ORDER BY START_TIME DESC;
```

### CORTEX_FUNCTIONS_QUERY_USAGE_HISTORY

Per-query breakdown (grouped by model):

```sql
SELECT * FROM SNOWFLAKE.ACCOUNT_USAGE.CORTEX_FUNCTIONS_QUERY_USAGE_HISTORY
WHERE QUERY_ID = '<query-id>';
```

### METERING_DAILY_HISTORY (High-Level)

```sql
SELECT * FROM SNOWFLAKE.ACCOUNT_USAGE.METERING_DAILY_HISTORY
WHERE SERVICE_TYPE = 'AI_SERVICES';
```

### Service-Specific Views

| View | What It Tracks |
|------|---------------|
| `CORTEX_FUNCTIONS_USAGE_HISTORY` | AI SQL functions (AI_COMPLETE, etc.) |
| `CORTEX_FUNCTIONS_QUERY_USAGE_HISTORY` | Per-query function breakdown |
| `CORTEX_REST_API_USAGE_HISTORY` | Cortex REST API calls |
| `CORTEX_ANALYST_USAGE_HISTORY` | Cortex Analyst messages |
| `CORTEX_SEARCH_DAILY_USAGE_HISTORY` | Cortex Search queries + storage |
| `CORTEX_FINE_TUNING_USAGE_HISTORY` | Fine-tuning training token costs |
| `CORTEX_PROVISIONED_THROUGHPUT_USAGE_HISTORY` | Reserved capacity usage |
| `METERING_DAILY_HISTORY` | High-level (SERVICE_TYPE = AI_SERVICES) |

### Fine-Tuning Cost Formula

```
Fine-tuning cost = number of input tokens × number of epochs trained
```

To verify trained tokens for a completed job:
```sql
-- Returns: trained_tokens, training_loss, validation_loss, status
SELECT SNOWFLAKE.CORTEX.FINETUNE('DESCRIBE', '<job_id>');
```

## Service Types in Billing

| SERVICE_TYPE | What It Covers |
|-------------|---------------|
| `AI_SERVICES` | Legacy umbrella for all Cortex features |
| `AI_FUNCTIONS` | Cortex AI SQL functions specifically |
| `AI_INFERENCE` | Cortex REST API (billed in dollars) |
| `CORTEX_AGENTS` | Agents API and orchestrator |
| `CORTEX_CODE_CLI` | Cortex Code CLI |
| `CORTEX_CODE_SNOWSIGHT` | Cortex Code in Snowsight |
| `SNOWFLAKE_INTELLIGENCE` | CoWork / Snowflake Intelligence |

---

## Billing Rules (Exam-Critical)

| Function Type | What's Billed |
|---------------|---------------|
| Generative (AI_COMPLETE, AI_CLASSIFY, etc.) | Input + output tokens |
| Embedding (AI_EMBED, AI_SIMILARITY) | Input tokens only |
| Document (AI_PARSE_DOCUMENT) | Per page (970 tokens/page) |
| Audio (AI_TRANSCRIBE) | 50 tokens/second |
| AI_COUNT_TOKENS | Compute only (no token charges) |
| Cortex Guard (guardrails) | Additional input tokens |
| Cortex Analyst (direct API) | Per message |
| Cortex Analyst (via Agents) | Per token |

## Cost Control Strategies

### 1. Usage Alerts

```sql
-- Create resource monitor for AI spending
CREATE RESOURCE MONITOR ai_spending_monitor
  WITH CREDIT_QUOTA = 1000
  TRIGGERS
    ON 75 PERCENT DO NOTIFY
    ON 90 PERCENT DO NOTIFY
    ON 100 PERCENT DO SUSPEND;
```

### 2. Per-User Spending Limits (Quotas)

```sql
-- Set spending quota per user
ALTER USER analyst_user SET 
  CORTEX_BUDGET_LIMIT = 100;  -- credits per period
```

### 3. Model Restrictions

Limit expensive models to specific roles:
```sql
-- Only grant expensive models to data science
ALTER ACCOUNT SET CORTEX_MODELS_ALLOWLIST = 'None';
GRANT APPLICATION ROLE SNOWFLAKE."CORTEX-MODEL-ROLE-LLAMA3.1-8B" TO ROLE PUBLIC;
GRANT APPLICATION ROLE SNOWFLAKE."CORTEX-MODEL-ROLE-CLAUDE-SONNET-4-6" TO ROLE data_science;
```

### 4. Warehouse Control

```sql
-- Use MEDIUM or smaller (larger doesn't help)
ALTER WAREHOUSE ai_wh SET WAREHOUSE_SIZE = 'MEDIUM';
```

## Monitoring Queries

```sql
-- Daily AI spending by service type
SELECT 
    DATE_TRUNC('day', START_TIME) AS day,
    SERVICE_TYPE,
    SUM(CREDITS_USED) AS total_credits
FROM SNOWFLAKE.ACCOUNT_USAGE.METERING_DAILY_HISTORY
WHERE SERVICE_TYPE LIKE '%AI%' OR SERVICE_TYPE LIKE '%CORTEX%'
GROUP BY 1, 2
ORDER BY 1 DESC;

-- Top users by AI function usage
SELECT 
    USER_NAME,
    FUNCTION_NAME,
    COUNT(*) AS call_count,
    SUM(TOKENS_PRODUCED + TOKENS_CONSUMED) AS total_tokens
FROM SNOWFLAKE.ACCOUNT_USAGE.CORTEX_FUNCTIONS_USAGE_HISTORY
WHERE START_TIME > DATEADD(day, -7, CURRENT_TIMESTAMP())
GROUP BY 1, 2
ORDER BY total_tokens DESC;

-- Cost per model
SELECT 
    MODEL_NAME,
    SUM(CREDITS_USED) AS total_credits,
    SUM(TOKENS_CONSUMED) AS input_tokens,
    SUM(TOKENS_PRODUCED) AS output_tokens
FROM SNOWFLAKE.ACCOUNT_USAGE.CORTEX_FUNCTIONS_USAGE_HISTORY
GROUP BY 1
ORDER BY total_credits DESC;
```

## Exam Tips

1. **METERING_DAILY_HISTORY** with `SERVICE_TYPE = 'AI_SERVICES'` for high-level tracking
2. **CORTEX_FUNCTIONS_QUERY_USAGE_HISTORY** for per-query breakdown
3. **Input + output tokens** billed for generative functions
4. **Only input tokens** for embedding functions
5. **970 tokens per page** for document parsing
6. **50 tokens per second** for audio transcription
7. **Warehouse MEDIUM or smaller** — larger doesn't help
8. **AI_COUNT_TOKENS** has no token charges (use to estimate costs)
9. **Cortex Guard** adds additional token charges on top of AI_COMPLETE
10. **REST API** billed in dollars, not credits
