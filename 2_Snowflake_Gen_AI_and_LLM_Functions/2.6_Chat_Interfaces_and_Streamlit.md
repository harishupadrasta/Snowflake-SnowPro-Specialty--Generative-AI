## Streamlit in Snowflake (SiS)

Streamlit apps run **natively inside Snowflake** — no external infrastructure needed. They're the primary way to build interactive AI chat interfaces.

### Basic RAG Chatbot Pattern

```python
import streamlit as st
from snowflake.snowpark.context import get_active_session
from snowflake.core import Root

session = get_active_session()
root = Root(session)

# Connect to Cortex Search
search_service = (root
    .databases["MY_DB"].schemas["MY_SCHEMA"]
    .cortex_search_services["my_search_service"]
)

st.title("Knowledge Base Assistant")

if "messages" not in st.session_state:
    st.session_state.messages = []

# Display chat history
for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.write(msg["content"])

# User input
if prompt := st.chat_input("Ask a question"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    
    # RAG: Search for context
    results = search_service.search(query=prompt, columns=["content"], limit=5)
    context = "\n".join([r["content"] for r in results.results])
    
    # Generate response
    full_prompt = f"Context: {context}\n\nQuestion: {prompt}\nAnswer:"
    response = session.sql(
        "SELECT AI_COMPLETE('llama3.1-70b', ?)", [full_prompt]
    ).collect()[0][0]
    
    st.session_state.messages.append({"role": "assistant", "content": response})
    with st.chat_message("assistant"):
        st.write(response)
```

---

## Key Streamlit + Cortex Components

| Component | Purpose |
|-----------|---------|
| `st.chat_input()` | User text input for chat |
| `st.chat_message()` | Display chat bubbles |
| `st.session_state` | Persist conversation history |
| `get_active_session()` | Connect to Snowflake from SiS |
| `Root(session)` | Access Cortex Search services |
| `session.sql()` | Execute AI functions |

## Deploying Streamlit in Snowflake

```sql
CREATE STREAMLIT my_chatbot
  ROOT_LOCATION = '@my_stage/chatbot/'
  MAIN_FILE = 'app.py'
  QUERY_WAREHOUSE = my_warehouse;
```

## Required Privileges for Streamlit + Cortex (Exam-Critical)

To use AI functions (AI_COMPLETE, AI_CLASSIFY, etc.) in a Streamlit-in-Snowflake app, the user's role needs ALL THREE:

```sql
-- Layer 1: Account privilege (default: granted to PUBLIC)
GRANT USE AI FUNCTIONS ON ACCOUNT TO ROLE my_role;

-- Layer 2: Database role (default: CORTEX_USER granted to PUBLIC)
GRANT DATABASE ROLE SNOWFLAKE.CORTEX_USER TO ROLE my_role;

-- Layer 3: Object access
GRANT USAGE ON DATABASE my_db TO ROLE my_role;
GRANT USAGE ON SCHEMA my_db.my_schema TO ROLE my_role;
```

**Key:** Users need BOTH `USE AI FUNCTIONS` (account privilege) AND a database role (CORTEX_USER or AI_FUNCTIONS_USER) AND USAGE on objects. Missing any one = fails.

## Exam Tips

1. **Streamlit in Snowflake** = primary method for building chat UIs
2. **get_active_session()** connects to Snowflake within SiS
3. **st.session_state** persists chat history across reruns
4. **RAG pattern**: Search → Context → AI_COMPLETE → Response
5. **No external hosting** needed — runs inside Snowflake
6. **CREATE STREAMLIT** requires QUERY_WAREHOUSE for compute
