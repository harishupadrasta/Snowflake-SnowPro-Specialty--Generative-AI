# 2.1 AI_COMPLETE and General Functions

> **Exam Domain:** 2.0 — Snowflake Gen AI Functions (38%)  
> **Exam Objective:** Understand AI_COMPLETE syntax, parameters, structured output, and advanced features

---

## AI_COMPLETE Overview

AI_COMPLETE is the **foundational function** in Snowflake Cortex AI. It generates text completions using any supported LLM model and supports text, images, audio, and video input.

---

## Three Input Variants

### 1. Single String (Most Common on Exam)

```sql
AI_COMPLETE( <model>, <prompt> [, <model_parameters>, <response_format>, <show_details>] )
```

```sql
SELECT AI_COMPLETE('llama3.1-70b', 'What is Snowflake Cortex?');
```

### 2. Single Image

```sql
AI_COMPLETE( <model>, <prompt>, <file> [, <model_parameters>, <response_format>] )
```

```sql
SELECT AI_COMPLETE(
    'claude-sonnet-4-6',
    'Describe this image in detail',
    TO_FILE('@my_stage', 'photo.jpg')
);
```

### 3. Prompt Object (Multi-file, Conversations)

```sql
AI_COMPLETE( <model>, <prompt_object> [, <model_parameters>, <response_format>] )
```

```sql
SELECT AI_COMPLETE(
    'claude-sonnet-4-6',
    PROMPT('Compare {0} to {1}',
        TO_FILE('@imgs', 'chart1.png'),
        TO_FILE('@imgs', 'chart2.png')
    )
);
```

## Model Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `temperature` | 0-1 | 0 | Randomness (higher = more creative) |
| `top_p` | 0-1 | 0 | Nucleus sampling (alternative to temperature) |
| `max_tokens` | Integer | 4096 | Maximum output tokens |
| `guardrails` | Boolean | FALSE | Enable Cortex Guard (safety filter) |

```sql
SELECT AI_COMPLETE(
    model => 'mistral-large2',
    prompt => 'Write a creative story about AI',
    model_parameters => {
        'temperature': 0.7,
        'max_tokens': 500,
        'guardrails': TRUE
    }
);
```

## Structured Output (Exam-Critical)

### Method 1: JSON Schema

```sql
SELECT AI_COMPLETE(
    model => 'llama3.3-70b',
    prompt => 'Extract customer info: Sarah Jones at 123 Main St, Portland OR',
    response_format => {
        'type': 'json',
        'schema': {
            'type': 'object',
            'properties': {
                'name': {'type': 'string'},
                'address': {'type': 'string'},
                'city': {'type': 'string'},
                'state': {'type': 'string'}
            },
            'required': ['name', 'address']
        }
    }
);
```

### Method 2: TYPE Literal (SQL Types)

```sql
SELECT AI_COMPLETE(
    model => 'llama3.3-70b',
    prompt => 'Extract: 3 items totaling $418.49',
    response_format => TYPE OBJECT(
        items_count NUMBER,
        total_price NUMBER,
        currency STRING
    )
);
```

### Key Rules for Structured Output

| Rule | Detail |
|------|--------|
| **OpenAI models require** | `additionalProperties: false` + all fields in `required` |
| **Top-level must be** | OBJECT (both JSON schema and TYPE literal) |
| **No spaces in keys** | Property names: letters, digits, hyphen, underscore only |
| **Max key length** | 64 characters |
| **Unsupported types** | VARIANT, MAP, Date/Time types (in TYPE literals) |
| **$ref scope** | Only within the schema (no external URLs) |
| **$defs placement** | Must be at top level of schema |

## show_details Argument

Returns token usage metadata:

```sql
SELECT AI_COMPLETE(
    model => 'deepseek-r1',
    prompt => 'Hello world',
    show_details => TRUE
);
```

**Response:**
```json
{
    "choices": [{"messages": "Hello! How can I help..."}],
    "created": 1708536426,
    "model": "deepseek-r1",
    "usage": {
        "completion_tokens": 15,
        "prompt_tokens": 5,
        "guardrail_tokens": 0,
        "total_tokens": 20
    }
}
```

---

## Cortex Guard

Built on Meta's Llama Guard 3. Filters unsafe responses:

```sql
SELECT AI_COMPLETE(
    model => 'mistral-large2',
    prompt => user_input,
    model_parameters => {'guardrails': TRUE}
);
```

**Key facts:**
- Evaluates LLM output BEFORE returning to user
- Filters: violence, hate, sexual content, self-harm
- **Additional token charges** (input tokens based on AI_COMPLETE output)
- Set via `model_parameters` OR account-level `AI_SETTINGS`

## Error Handling

### return_error_details Parameter

```sql
SELECT AI_COMPLETE(
    'llama3.1-70b', 
    input_text, 
    return_error_details => TRUE
) FROM my_table;
```

Returns: `{"value": "response text", "error": null}` or `{"value": null, "error": "error message"}`

### TRY_COMPLETE (Error-Safe Variant)

```sql
SELECT TRY_COMPLETE('llama3.1-70b', 'prompt text');
-- Returns NULL on error instead of failing the query
```

> **Exam Tip:** Use `TRY_COMPLETE` for batch processing where individual row failures shouldn't stop the entire query.

## Multimodal Capabilities

| Model | Text | Images | Audio | Video |
|-------|------|--------|-------|-------|
| claude-sonnet-4-6 | ✓ | ✓ (20 files) | - | - |
| openai-gpt-4.1 | ✓ | ✓ (5 files) | - | - |
| llama4-maverick | ✓ | ✓ (10 files) | - | - |
| gemini-3.1-pro | ✓ | ✓ | ✓ (10 files) | ✓ (10 files) |
| gemini-3.5-flash | ✓ | ✓ | ✓ (10 files) | ✓ (10 files) |

**File requirements:**
- Must be on internal/external stages with server-side encryption
- Use `TO_FILE('@stage', 'filename')` to reference files
- Images: JPEG, PNG, WEBP, GIF, BMP (max 10MB per file)
- Audio: WAV, MP3, AIFF, AAC, OGG, FLAC (max 100MB combined)
- Video: MP4, MPEG, MOV, AVI (max 100MB combined)

## COMPLETE (Legacy Namespace)

```sql
-- Legacy (still valid on exam)
SELECT SNOWFLAKE.CORTEX.COMPLETE('llama3.1-70b', 'Hello');

-- Current (preferred)
SELECT AI_COMPLETE('llama3.1-70b', 'Hello');
```

Both are equivalent. The exam tests both namespaces.

## Cost Considerations

| What | Billing |
|------|---------|
| Input tokens | Billed per million tokens |
| Output tokens | Billed per million tokens |
| Guardrails | Additional input tokens (based on output size) |
| Audio | 50 tokens per second |
| Structured output schema overhead | Increases token count |
| Temperature/parameters | No additional cost |

> **Exam Tip:** Warehouse size no larger than **MEDIUM** for AI functions. Larger warehouses don't improve performance.

---

## Exam Tips

1. **Three input variants**: single string, single image, prompt object
2. **Structured output** supports JSON schema OR TYPE literals (not both)
3. **show_details = TRUE** returns token usage metadata
4. **guardrails = TRUE** in model_parameters enables Cortex Guard
5. **TRY_COMPLETE** returns NULL on error (batch-safe)
6. **return_error_details = TRUE** returns {value, error} object
7. **Default temperature = 0** (deterministic)
8. **Default max_tokens = 4096**
9. **Both namespaces valid**: AI_COMPLETE and SNOWFLAKE.CORTEX.COMPLETE
10. **OpenAI models** require `additionalProperties: false` in JSON schemas
