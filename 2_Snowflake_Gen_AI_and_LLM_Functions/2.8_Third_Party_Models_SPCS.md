# 2.8 Third-Party Models and SPCS

> **Exam Domain:** 2.0 — Snowflake Gen AI Functions (38%)  
> **Exam Objective:** Deploy and manage custom models via SPCS and Model Registry

---

## When to Use SPCS vs Built-in AI Functions

| Scenario | Solution |
|----------|----------|
| Standard text analysis | AI Functions (serverless, no setup) |
| Custom fine-tuned model | SPCS + Model Registry |
| Specific Hugging Face model | SPCS container deployment |
| GPU-intensive training | SPCS compute pool |
| Proprietary model | SPCS (full control) |
| Standard embeddings | AI_EMBED (serverless) |

## Cortex Fine-Tuning

Fine-tune supported models on your data:

```sql
SELECT SNOWFLAKE.CORTEX.FINETUNE(
    'CREATE',
    'my_finetuned_model',
    'llama3.1-8b',
    'SELECT prompt, completion FROM training_data',
    'SELECT prompt, completion FROM validation_data'
);
```

**Supported base models for fine-tuning:**
- llama3.1-8b, llama3.1-70b
- mistral-7b

**Training data format:** Table with `prompt` and `completion` columns.

**Check status:**
```sql
SELECT SNOWFLAKE.CORTEX.FINETUNE('DESCRIBE', 'my_finetuned_model');
```

## SPCS Deployment Workflow

```
1. Build Docker image locally
2. Push to Snowflake Image Repository
3. Create Compute Pool (GPU)
4. Create Service from spec
5. Query via service function or endpoint
```

### Key Commands

```sql
-- Create image repository
CREATE IMAGE REPOSITORY my_repo;

-- Show repository URL for docker push
SHOW IMAGE REPOSITORIES;
-- Push: docker push <repo_url>/my-model:v1

-- Create GPU compute pool
CREATE COMPUTE POOL ml_pool
  MIN_NODES = 1 MAX_NODES = 2
  INSTANCE_FAMILY = GPU_NV_S;

-- Deploy service
CREATE SERVICE my_model_service
  IN COMPUTE POOL ml_pool
  FROM SPECIFICATION $$
  spec:
    containers:
      - name: model
        image: /db/schema/my_repo/my-model:v1
        resources:
          requests:
            nvidia.com/gpu: 1
    endpoints:
      - name: predict
        port: 8080
  $$;
```

## Model Registry

```python
from snowflake.ml.registry import Registry

reg = Registry(session, database_name="ML_DB", schema_name="MODELS")

# Register a model
mv = reg.log_model(
    model_name="sentiment_classifier",
    version_name="v2",
    model=trained_model,
    sample_input_data=X_sample
)

# Deploy as UDF
mv.deploy(deployment_name="predict_sentiment", permanent=True)
```

```sql
-- Use deployed model
SELECT predict_sentiment(review_text) FROM reviews;
```

## Exam Tips

1. **Cortex Fine-Tuning** uses `SNOWFLAKE.CORTEX.FINETUNE()` function
2. **SPCS** = custom Docker containers with GPU support
3. **Model Registry** = version + deploy as UDF (no containers needed for inference)
4. **GPU instance families**: GPU_NV_S (A10G), GPU_NV_M (A100), GPU_NV_L (multi-GPU)
5. **Image Repository** stores Docker images within Snowflake
6. **Fine-tuning training data** format: `prompt` and `completion` columns
7. **SPCS billing** = per compute-hour (not per token)
