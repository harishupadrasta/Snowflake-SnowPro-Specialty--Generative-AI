# 2.3 Vector Functions and Operations

> **Exam Domain:** 2.0 — Snowflake Gen AI Functions (38%)  
> **Exam Objective:** Understand vector embeddings, similarity calculations, and vector operations

---

## AI_EMBED — Generate Embeddings

```sql
-- Text embedding
SELECT AI_EMBED('snowflake-arctic-embed-l-v2.0', 'Hello world');
-- Returns: VECTOR(FLOAT, 1024)

-- Image embedding
SELECT AI_EMBED('voyage-multimodal-3', TO_FILE('@images', 'photo.jpg'));

-- Embed a column
SELECT text_content, AI_EMBED('snowflake-arctic-embed-m-v1.5', text_content) AS embedding
FROM documents;
```

### Available Embedding Models

| Model | Dimensions | Context | Language | Use Case |
|-------|-----------|---------|----------|----------|
| `snowflake-arctic-embed-m` | 768 | 512 tokens | English | Legacy |
| `snowflake-arctic-embed-m-v1.5` | 768 | 512 tokens | English | Default for Search |
| `snowflake-arctic-embed-l-v2.0` | 1024 | 512 tokens | Multilingual | High quality |
| `snowflake-arctic-embed-l-v2.0-8k` | 1024 | 8192 tokens | Multilingual | Long docs |
| `voyage-multilingual-2` | 1024 | 32,000 tokens | Multilingual | Very long text |
| `voyage-multimodal-3` | 1024 | — | — | Images + text |
| `e5-base-v2` | 768 | 512 tokens | English | Legacy |
| `multilingual-e5-large` | 1024 | 512 tokens | Multilingual | Legacy |

### Access Control

- Requires `SNOWFLAKE.CORTEX_USER` OR `SNOWFLAKE.CORTEX_EMBED_USER`
- `CORTEX_EMBED_USER` is the least-privilege option for embedding-only access

## AI_MULTI_EMBED — Video Embeddings

```sql
SELECT AI_MULTI_EMBED('twelvelabs-marengo-embed-3-0', video_file) AS embeddings
FROM video_table;
```

- Returns embeddings per modality: visual, audio, transcription
- Each embedding has `start_sec` and `end_sec` timestamps
- 512-dimensional vectors
- Available in US East (N. Virginia) only; cross-region supported
- Max video duration: 4 hours

## Vector Similarity Functions

### VECTOR_COSINE_SIMILARITY

Measures angular similarity (most common for text/semantic search):

```sql
SELECT VECTOR_COSINE_SIMILARITY(
    AI_EMBED('snowflake-arctic-embed-l-v2.0', 'machine learning'),
    AI_EMBED('snowflake-arctic-embed-l-v2.0', 'artificial intelligence')
) AS similarity;
-- Returns: ~0.85 (high similarity)
```

- Range: -1 to 1 (1 = identical direction)
- **Most commonly used** for semantic similarity

### VECTOR_L2_DISTANCE (Euclidean)

```sql
SELECT VECTOR_L2_DISTANCE(vec1, vec2) AS distance;
```

- Range: 0 to ∞ (0 = identical)
- Lower = more similar

### VECTOR_L1_DISTANCE (Manhattan)

```sql
SELECT VECTOR_L1_DISTANCE(vec1, vec2) AS distance;
```

- Range: 0 to ∞ (0 = identical)
- Sum of absolute differences

### VECTOR_INNER_PRODUCT (Dot Product)

```sql
SELECT VECTOR_INNER_PRODUCT(vec1, vec2) AS product;
```

- Range: depends on magnitudes
- Higher = more similar (for normalized vectors)

## Vector Utility Functions

### VECTOR_TRUNCATE

Reduces vector dimensions (for storage optimization):

```sql
SELECT VECTOR_TRUNCATE(embedding, 256) AS short_embedding
FROM documents;
-- Reduces 1024-dim vector to 256 dimensions
```

### VECTOR_NORMALIZE

Normalizes a vector to unit length:

```sql
SELECT VECTOR_NORMALIZE(embedding) AS normalized
FROM documents;
```

### VECTOR_SUM, VECTOR_AVG, VECTOR_MIN, VECTOR_MAX

Aggregate vector operations:

```sql
-- Average embedding for a cluster
SELECT category, VECTOR_AVG(embedding) AS centroid
FROM documents
GROUP BY category;

-- Element-wise sum
SELECT VECTOR_SUM(embedding) FROM documents;
```

## VECTOR Data Type

```sql
-- Create table with vector column
CREATE TABLE embeddings (
    id INT,
    text VARCHAR,
    embedding VECTOR(FLOAT, 1024)
);

-- Insert embeddings
INSERT INTO embeddings
SELECT id, text, AI_EMBED('snowflake-arctic-embed-l-v2.0', text)
FROM source_data;
```

### Vector Type Syntax

```sql
VECTOR(FLOAT, <dimensions>)
VECTOR(INT, <dimensions>)
```

## Semantic Search Pattern

```sql
-- Find most similar documents to a query
WITH query_embedding AS (
    SELECT AI_EMBED('snowflake-arctic-embed-l-v2.0', 'network issues') AS qvec
)
SELECT 
    d.text,
    VECTOR_COSINE_SIMILARITY(d.embedding, q.qvec) AS similarity
FROM documents d
CROSS JOIN query_embedding q
ORDER BY similarity DESC
LIMIT 10;
```

## Exam Tips

1. **AI_EMBED** returns VECTOR type — only input tokens billed
2. **VECTOR_COSINE_SIMILARITY** is the standard for semantic search (range -1 to 1)
3. **VECTOR_L2_DISTANCE** — lower = more similar (Euclidean)
4. **CORTEX_EMBED_USER** — least-privilege role for embedding access
5. **snowflake-arctic-embed-m-v1.5** is the default model (768 dimensions)
6. **voyage-multimodal-3** handles images (1024 dimensions)
7. **VECTOR_TRUNCATE** reduces dimensions (storage optimization)
8. **AI_MULTI_EMBED** for video — returns per-segment, per-modality embeddings
9. **512 tokens** context limit for most embedding models (split long text first)
10. **Vector columns** can be used in tables, views, and similarity queries
