# 2.2 Task-Specific AI Functions

> **Exam Domain:** 2.0 — Snowflake Gen AI Functions (38%)  
> **Exam Objective:** Know syntax, use cases, and behavior of each task-specific function

---

## Function Reference Table

| Function | Input | Output | Billing |
|----------|-------|--------|---------|
| AI_CLASSIFY | Text/image + categories | Category label | Input + output tokens |
| AI_EXTRACT | Text/file + schema | JSON object | Input + output tokens |
| AI_FILTER | Text/image + condition | Boolean | Input + output tokens |
| AI_AGG | Multiple rows + question | Text insight | Input + output tokens |
| AI_SENTIMENT | Text | Float (-1 to 1) | Input + output tokens |
| AI_SUMMARIZE_AGG | Multiple rows | Summary text | Input + output tokens |
| SUMMARIZE | Single text | Summary text | Input + output tokens |
| AI_TRANSLATE | Text + target language | Translated text | Input + output tokens |
| AI_REDACT | Text + entity types | Redacted text | Input + output tokens |
| AI_TRANSCRIBE | Audio/video file | JSON transcript | 50 tokens/second |

## AI_CLASSIFY

Classifies input into one of the provided categories.

```sql
-- Text classification
SELECT AI_CLASSIFY(
    'The laptop screen is cracked and needs replacement',
    ['Hardware Issue', 'Software Issue', 'Billing', 'General Inquiry']
) AS category;
-- Returns: 'Hardware Issue'

-- With descriptions for better accuracy
SELECT AI_CLASSIFY(
    review_text,
    [
        {'label': 'Positive', 'description': 'Customer is happy with the product'},
        {'label': 'Negative', 'description': 'Customer is unhappy or complaining'},
        {'label': 'Neutral', 'description': 'Factual statement without emotion'}
    ]
) FROM reviews;

-- Image classification
SELECT AI_CLASSIFY(
    TO_FILE('@images', 'photo.jpg'),
    ['Landscape', 'Portrait', 'Document', 'Product']
);
```

**Key facts:**
- Labels, descriptions, and examples count as **input tokens for EACH ROW**
- Supports text AND images
- Returns a single label from the provided array

## AI_EXTRACT

Extracts structured data from text or files into a JSON object.

```sql
-- Extract from text
SELECT AI_EXTRACT(
    'John Smith called on Jan 15 about order #12345. His email is john@example.com.',
    {'name': 'string', 'date': 'string', 'order_id': 'string', 'email': 'string'}
);
-- Returns: {"name": "John Smith", "date": "Jan 15", "order_id": "12345", "email": "john@example.com"}

-- Extract from a document
SELECT AI_EXTRACT(
    TO_FILE('@documents', 'invoice.pdf'),
    {'vendor': 'string', 'amount': 'number', 'date': 'string', 'items': 'array'}
);
```

**Key facts:**
- The `responseFormat` (schema) argument counts as input tokens
- For documents with pages: 970 tokens per page as input tokens
- Both input AND output tokens billed

---

## AI_FILTER

Returns TRUE or FALSE based on a natural language condition.

```sql
-- Filter reviews mentioning shipping issues
SELECT * FROM reviews
WHERE AI_FILTER(
    review_text,
    'Mentions a problem with shipping or delivery'
);

-- Filter images
SELECT * FROM product_images
WHERE AI_FILTER(
    TO_FILE('@images', image_path),
    'Shows a damaged or defective product'
);
```

**Key facts:**
- Returns BOOLEAN (true/false)
- Great for WHERE clauses
- Supports text AND images

## AI_AGG (Aggregate Function)

Aggregates insights across multiple rows — **no context window limit** (processes in batches).

```sql
-- Analyze themes across all complaints
SELECT AI_AGG(
    complaint_text,
    'What are the top 3 recurring themes in these customer complaints?'
) FROM support_tickets
WHERE created_date > CURRENT_DATE - 30;

-- Group-level analysis
SELECT department, AI_AGG(
    feedback_text,
    'Summarize the key feedback points'
) AS summary
FROM employee_feedback
GROUP BY department;
```

**Key facts:**
- **Aggregate function** (works with GROUP BY)
- Processes rows in batches — no context window limit
- Can handle millions of rows
- Returns a single text insight per group
- Does NOT require `USE AI FUNCTIONS` privilege if user has `CORTEX_USER`

## AI_SENTIMENT

Returns sentiment information. Two output formats available:

### Overall sentiment (no entities — returns float -1 to 1):

```sql
SELECT AI_SENTIMENT('Great product but expensive');
-- Returns: 0.3 (slightly positive)
```

### Aspect-based sentiment (with entities — returns OBJECT with categories):

```sql
SELECT AI_SENTIMENT(
    'The food was amazing but the service was terrible',
    ['food', 'service', 'ambiance']
);
```

**Returns:**
```json
{
  "categories": [
    {"name": "overall", "sentiment": "mixed"},
    {"name": "food", "sentiment": "positive"},
    {"name": "service", "sentiment": "negative"},
    {"name": "ambiance", "sentiment": "unknown"}
  ]
}
```

### Key facts:
- **Without entities**: Returns FLOAT between -1 and 1
- **With entities array**: Returns OBJECT with categories field (positive/negative/neutral/mixed/unknown)
- Supports up to 10 entities (max 30 chars each)
- Multilingual: English, French, German, Hindi, Italian, Spanish, Portuguese
- Context window: 2,048 tokens

### Legacy Function: ENTITY_SENTIMENT (SNOWFLAKE.CORTEX)

```sql
-- Legacy (being deprecated by end of 2026)
SELECT SNOWFLAKE.CORTEX.ENTITY_SENTIMENT(text, ['entity1', 'entity2']);
-- Returns OBJECT with categories field
```

> **Exam Tip:** Both `AI_SENTIMENT` (new) and `SNOWFLAKE.CORTEX.ENTITY_SENTIMENT` (legacy) can return the OBJECT with categories. The exam may reference either.

### Legacy Function: SENTIMENT (SNOWFLAKE.CORTEX)

```sql
-- Legacy version (returns float only)
SELECT SNOWFLAKE.CORTEX.SENTIMENT('Great product!');
-- Returns: 0.85
```

## AI_SUMMARIZE_AGG (Aggregate Function)

Summarizes content across multiple rows.

```sql
SELECT AI_SUMMARIZE_AGG(article_text) AS daily_summary
FROM news_articles
WHERE publish_date = CURRENT_DATE;

-- Per-category summaries
SELECT category, AI_SUMMARIZE_AGG(content) AS summary
FROM documents
GROUP BY category;
```

**Key facts:**
- **Aggregate function** (works with GROUP BY)
- No context window limit (batched processing)
- Returns a text summary of all input rows

---

## SUMMARIZE (Single Row)

Summarizes a single text value.

```sql
SELECT SUMMARIZE(long_article_text) AS summary
FROM articles
WHERE article_id = 123;

-- Legacy namespace
SELECT SNOWFLAKE.CORTEX.SUMMARIZE(text_column) FROM table;
```

## AI_TRANSLATE

Translates text to a target language.

```sql
SELECT AI_TRANSLATE(
    'Hello, how are you?',
    'en',    -- source language (ISO 639-1)
    'fr'     -- target language
);
-- Returns: 'Bonjour, comment allez-vous?'

-- Translate a column
SELECT original_text, AI_TRANSLATE(original_text, 'auto', 'en') AS english_text
FROM multilingual_reviews;
```

**Key facts:**
- Uses ISO 639-1 language codes (en, fr, de, es, ja, etc.)
- Source can be 'auto' for auto-detection
- Both input and output tokens billed

---

## AI_REDACT

Removes personally identifiable information (PII) from text.

```sql
SELECT AI_REDACT(
    'Call John Smith at 555-0123 or email john.smith@company.com',
    ['phone_number', 'email_address', 'person_name']
);
-- Returns: 'Call [PERSON_NAME] at [PHONE_NUMBER] or email [EMAIL_ADDRESS]'

-- Redact all PII types
SELECT AI_REDACT(customer_notes) FROM support_tickets;
```

**Key facts:**
- Entity types: person_name, phone_number, email_address, SSN, credit_card, address, etc.
- If no entity types specified, redacts all recognized PII
- Both input and output tokens billed

## AI_TRANSCRIBE

Converts audio/video to text with timestamps and speaker identification.

```sql
SELECT AI_TRANSCRIBE(
    TO_FILE('@audio_stage', 'meeting_recording.mp3')
);
```

**Response format:**
```json
{
    "audio_duration": 3600.5,
    "text": "Welcome to the meeting...",
    "segments": [
        {
            "start": 0.0,
            "end": 5.2,
            "text": "Welcome to the meeting",
            "speaker": "SPEAKER_01"
        }
    ]
}
```

**Key facts:**
- Supports: WAV, MP3, AIFF, AAC, OGG, FLAC, M4A, MP4, PCM, WEBM
- Video: MP4, MPEG, MOV, AVI, FLV, MPG, WEBM, WMV, 3GPP
- Billed at **50 tokens per second** of audio
- Returns JSON with text, duration, segments, speaker IDs
- Requires `gemini-3.1-pro` or `gemini-3.5-flash` model

---

## AI_SIMILARITY

Computes semantic similarity between two inputs.

```sql
SELECT AI_SIMILARITY(
    'voyage-multimodal-3',
    'A dog playing in the park',
    TO_FILE('@images', 'puppy.jpg')
) AS similarity_score;
-- Returns: 0.85 (high similarity)
```

**Key facts:**
- Returns FLOAT (0 to 1, where 1 = identical meaning)
- Supports text-to-text, text-to-image, image-to-image
- Only input tokens billed (embedding function)

---

## Exam Tips

1. **AI_AGG and AI_SUMMARIZE_AGG** are aggregate functions (use GROUP BY)
2. **AI_SENTIMENT** returns a FLOAT (-1 to 1), not a label
3. **AI_FILTER** returns BOOLEAN — perfect for WHERE clauses
4. **AI_CLASSIFY** labels/descriptions count as input tokens PER ROW
5. **AI_TRANSCRIBE** bills at 50 tokens/second of audio
6. **AI_EXTRACT** responseFormat is billed as input tokens
7. **AI_REDACT** replaces PII with bracketed placeholders
8. **No model parameter needed** for AI_SENTIMENT, SUMMARIZE, AI_TRANSLATE (use default models)
9. **AI_AGG has no context window limit** — handles millions of rows via batching
10. **Documents** billed at 970 tokens per page for AI_EXTRACT
