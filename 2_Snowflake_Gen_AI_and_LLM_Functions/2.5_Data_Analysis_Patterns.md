# 2.5 Data Analysis Patterns

> **Exam Domain:** 2.0 — Snowflake Gen AI Functions (38%)  
> **Exam Objective:** Apply AI functions to common data analysis scenarios

---

## Pattern 1: Classification at Scale

```sql
-- Classify support tickets into categories
SELECT 
    ticket_id,
    subject,
    AI_CLASSIFY(description, ['Billing', 'Technical', 'Account', 'Feature Request']) AS category
FROM support_tickets;

-- Multi-label with AI_COMPLETE + structured output
SELECT 
    ticket_id,
    AI_COMPLETE(
        'llama3.1-70b',
        CONCAT('Classify this ticket. Assign priority and category: ', description),
        response_format => {
            'type': 'json',
            'schema': {
                'type': 'object',
                'properties': {
                    'category': {'type': 'string'},
                    'priority': {'type': 'string', 'enum': ['low', 'medium', 'high', 'critical']},
                    'sentiment': {'type': 'string'}
                }
            }
        }
    ) AS analysis
FROM support_tickets;
```

## Pattern 2: Entity Extraction Pipeline

```sql
-- Extract structured data from unstructured text
SELECT 
    email_id,
    AI_EXTRACT(
        email_body,
        {
            'sender_name': 'string',
            'company': 'string',
            'request_type': 'string',
            'deadline': 'string',
            'phone': 'string'
        }
    ) AS extracted
FROM emails;
```

## Pattern 3: Sentiment Analysis with Aggregation

```sql
-- Per-product sentiment with distribution
SELECT 
    product_name,
    COUNT(*) AS review_count,
    AVG(AI_SENTIMENT(review_text)) AS avg_sentiment,
    COUNT(CASE WHEN AI_SENTIMENT(review_text) > 0.3 THEN 1 END) AS positive_count,
    COUNT(CASE WHEN AI_SENTIMENT(review_text) < -0.3 THEN 1 END) AS negative_count
FROM reviews
GROUP BY product_name
ORDER BY avg_sentiment DESC;

-- Aggregate insights across negative reviews
SELECT product_name, AI_AGG(
    review_text,
    'What are the most common complaints?'
) AS complaint_themes
FROM reviews
WHERE AI_SENTIMENT(review_text) < -0.3
GROUP BY product_name;
```

## Pattern 4: Content Enrichment

```sql
-- Enrich records with AI-generated metadata
CREATE TABLE enriched_articles AS
SELECT
    article_id,
    title,
    body,
    AI_CLASSIFY(body, ['Technology', 'Business', 'Science', 'Health', 'Sports']) AS category,
    AI_SENTIMENT(body) AS sentiment,
    AI_COMPLETE('llama3.1-8b', CONCAT('Generate 5 keywords for: ', LEFT(body, 500)),
        response_format => {'type': 'json', 'schema': {'type': 'object', 
            'properties': {'keywords': {'type': 'array', 'items': {'type': 'string'}}}}}
    ) AS keywords
FROM raw_articles;
```

## Pattern 5: Data Quality with AI_FILTER

```sql
-- Find rows with data quality issues
SELECT * FROM customer_records
WHERE AI_FILTER(address, 'This address appears incomplete or malformed');

-- Filter out irrelevant content
DELETE FROM scraped_data
WHERE NOT AI_FILTER(content, 'Contains substantive information about the product');
```

## Pattern 6: Translation Pipeline

```sql
-- Translate and store multilingual content
CREATE TABLE translated_reviews AS
SELECT
    review_id,
    original_language,
    original_text,
    AI_TRANSLATE(original_text, original_language, 'en') AS english_text
FROM multilingual_reviews
WHERE original_language != 'en';
```

## Pattern 7: PII Detection and Redaction

```sql
-- Redact before sharing data
CREATE VIEW safe_customer_notes AS
SELECT
    ticket_id,
    AI_REDACT(agent_notes, ['person_name', 'phone_number', 'email_address', 'ssn']) AS notes
FROM support_tickets;
```

---

## Exam Tips

1. **AI_AGG + GROUP BY** = per-group insights across many rows
2. **AI_FILTER in WHERE** = natural language filtering
3. **AI_CLASSIFY** for categorical labeling at scale
4. **Combine functions** — sentiment + classification + extraction in one query
5. **Structured output** from AI_COMPLETE when you need custom schemas
6. **Cost awareness** — AI functions bill per row, so LIMIT during development
