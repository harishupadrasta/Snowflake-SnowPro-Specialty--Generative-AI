# 1.6 Cortex Code

> **Exam Domain:** 1.0 — Snowflake for Gen AI Overview (18%)  
> **Exam Objective:** Understand Cortex Code capabilities and deployment options

---

## What is Cortex Code?

Cortex Code is Snowflake's **AI-powered development assistant** that helps write, debug, and optimize SQL, Python, and Snowflake configurations. It's available across multiple surfaces.

---

## Deployment Surfaces

| Surface | Description | Billing Service Type |
|---------|-------------|---------------------|
| **Snowsight (Copilot)** | Inline AI assistant in worksheets | `CORTEX_CODE_SNOWSIGHT` |
| **Desktop IDE** | Full standalone IDE application | `CORTEX_CODE_CLI` |
| **CLI** | Command-line interface | `CORTEX_CODE_CLI` |

---

## Key Capabilities

- **SQL generation** — Natural language → SQL queries
- **Code completion** — Inline suggestions while typing
- **Code explanation** — Explain existing queries
- **Debugging** — Identify and fix errors
- **Optimization** — Suggest performance improvements
- **Documentation** — Generate comments and docs

---

## Requirements

- **Cross-region inference required** — Cortex Code needs `CORTEX_ENABLED_CROSS_REGION` set to a value other than `DISABLED`
- **Role access** — Requires `SNOWFLAKE.COPILOT_USER` database role for Snowsight Copilot

### Enabling Access

```sql
-- Grant Copilot access in Snowsight
GRANT DATABASE ROLE SNOWFLAKE.COPILOT_USER TO ROLE developer_role;

-- Cross-region must be enabled (required for Cortex Code)
ALTER ACCOUNT SET CORTEX_ENABLED_CROSS_REGION = 'ANY_REGION';
```

---

## Exam Tips

1. **Requires cross-region inference** — won't work with `DISABLED` setting
2. **Three surfaces**: Snowsight, Desktop IDE, CLI
3. **Separate billing** — CORTEX_CODE_SNOWSIGHT vs CORTEX_CODE_CLI
4. **COPILOT_USER role** needed for Snowsight Copilot specifically
5. **Not the same as Cortex Agents** — Code assists developers, Agents serve end users
