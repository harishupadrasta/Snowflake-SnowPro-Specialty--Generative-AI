## Snowflake CoWork (Full Feature Set)

CoWork is the production-grade **agent chat interface** accessible at `https://ai.snowflake.com`.

### Key Capabilities

```
┌─────────────────────────────────────────────────────────────────┐
│                    SNOWFLAKE COWORK                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  CORE                         │  ADVANCED                         │
│  ────                         │  ────────                         │
│  • Natural language Q&A       │  • Deep Research (multi-step)     │
│  • Structured + unstructured  │  • Extended Thinking              │
│  • Auto-visualization         │  • Zero-setup file upload         │
│  • Multi-agent switching      │  • Artifacts (persistent charts)  │
│  • Feedback collection        │  • Automations (scheduled)        │
│  • Thread persistence         │  • Skills & Plugins catalog       │
│  • Private connectivity       │  • Microsoft Teams integration    │
│  • Mobile app (iOS)           │  • Vega-Lite chart types          │
│                               │  • Custom branding/theming        │
└─────────────────────────────────────────────────────────────────┘
```

### Deep Research Mode

For complex questions requiring multi-step analysis across data:

- Decomposes question into sub-investigations
- Runs parallel analysis across structured AND unstructured data
- Synthesizes findings into a structured report with citations
- Takes up to 10 minutes
- Use when: "Why has X been declining?", "What do these segments share?"

### Automations

Turn any report into a scheduled subscription:

- Re-runs questions on fresh data
- Emails results on a schedule
- Managed conversationally or via Automations tab

### Snowflake CoWork Object (Account-Level Management)

```sql
-- Create CoWork object (one per account)
CREATE SNOWFLAKE INTELLIGENCE SNOWFLAKE_INTELLIGENCE_OBJECT_DEFAULT;

-- Add agents to CoWork
ALTER SNOWFLAKE INTELLIGENCE SNOWFLAKE_INTELLIGENCE_OBJECT_DEFAULT 
  ADD AGENT my_db.my_schema.my_agent;

-- Remove agents
ALTER SNOWFLAKE INTELLIGENCE SNOWFLAKE_INTELLIGENCE_OBJECT_DEFAULT 
  DROP AGENT my_db.my_schema.my_agent;

-- Grant visibility to all users
GRANT USAGE ON SNOWFLAKE INTELLIGENCE SNOWFLAKE_INTELLIGENCE_OBJECT_DEFAULT TO ROLE PUBLIC;

-- Check if CoWork object exists
SHOW SNOWFLAKE INTELLIGENCES;
```

### CoWork Privileges

| Privilege | Object | Purpose |
|-----------|--------|---------|
| `CREATE SNOWFLAKE INTELLIGENCE` | Account | Create CoWork object |
| `USAGE` | CoWork object | View agents listed |
| `MODIFY` | CoWork object | Add/remove agents |
| `USAGE` | Agent | Run the agent |

### Restrict Users to CoWork Only

```sql
-- User can ONLY access CoWork, nothing else in Snowflake
ALTER USER data_consumer SET ALLOWED_INTERFACES = (SNOWFLAKE_INTELLIGENCE);
```

### Microsoft Teams Integration

CoWork agents are also accessible through Microsoft Teams and Microsoft 365 Copilot:
- Reuses same agents (no reconfiguration)
- OAuth 2.0 via Entra ID
- Respects all Snowflake RBAC
- Supports both Teams chat and M365 Copilot

## Cortex Code Agent SDK (Preview)

Build **agentic AI applications** in Python or TypeScript using the same tools that power Cortex Code.

### Installation

```bash
# CLI (required)
curl -LsS https://ai.snowflake.com/static/cc-scripts/install.sh | sh

# Python SDK
pip install cortex-code-agent-sdk

# TypeScript SDK
npm install cortex-code-agent-sdk
```

### Basic Usage

```python
import asyncio
from cortex_code_agent_sdk import query, AssistantMessage, CortexCodeAgentOptions

async def main():
    async for message in query(
        prompt="Explore the SALES.PUBLIC schema and summarize its tables",
        options=CortexCodeAgentOptions(
            cwd=".",
            allowed_tools=["SQL"],  # auto-approve SQL tool
        ),
    ):
        if isinstance(message, AssistantMessage):
            for block in message.content:
                if hasattr(block, "text"):
                    print(block.text, end="")

asyncio.run(main())
```

### Built-in Tools

| Tool | Description |
|------|-------------|
| Read | Read any file in working directory |
| Write | Create new files |
| Edit | Make precise edits to existing files |
| Bash | Run terminal commands and scripts |
| Glob | Find files by pattern |
| Grep | Search file contents |
| SQL | Execute SQL against Snowflake |

### Multi-Turn Sessions

```python
from cortex_code_agent_sdk import CortexCodeSDKClient, CortexCodeAgentOptions

async with CortexCodeSDKClient(CortexCodeAgentOptions(allowed_tools=["SQL"])) as client:
    await client.query("List tables in SALES.PUBLIC")
    async for msg in client.receive_response():
        pass
    
    # Second turn retains context
    await client.query("Now join the two largest tables")
    async for msg in client.receive_response():
        pass
```

### Session Options

| Option | Description |
|--------|-------------|
| `max_turns` | Limit agentic turns |
| `effort` | Thinking effort: minimal/low/medium/high/max |
| `model` | Model selection (default: "auto") |
| `allowed_tools` | Auto-approve specific tools |
| `mcp_servers` | Connect external MCP servers |
| `system_prompt` | Custom system prompt |
| `output_format` | Force JSON schema output |
| `plugins` | Load plugin directories |

## Agent Skills (Server-Side)

Skills are **modular, portable instruction packages** stored on stages or Git repos.

### SKILL.md Structure

```markdown
# Skill Name: forecaster
# Description: Generates quarterly revenue forecasts using historical data

## Instructions

1. Query the REVENUE_HISTORY table for the last 8 quarters
2. Calculate growth rate and seasonality patterns
3. Generate forecast with confidence intervals
4. Present results in a summary table
```

### Skill Sources

| Source | Path Format | Updates |
|--------|-------------|---------|
| Stage | `@db.schema.stage/skills/forecaster` | Immediate |
| Git (tag) | `@db.schema.repo/tags/latest/skills/forecaster` | After FETCH |
| Git (commit) | `@db.schema.repo/commits/abc123/skills/forecaster` | Immutable |
| Cortex Extension | `MY_DB.MY_SCHEMA.MY_EXTENSION` | On version publish |

### Adding Skills to Agent

```sql
ALTER AGENT my_agent
  MODIFY LIVE VERSION
  SET SPECIFICATION = $$
  {
    "skills": [
      {
        "name": "forecaster",
        "source": {
          "type": "STAGE",
          "path": "@db.schema.stage/skills/forecaster"
        }
      }
    ]
  }
  $$;
```

### Cortex Extensions (Skill Catalog)

Pre-packaged skills shared via Snowflake's catalog system:

```sql
-- Reference an extension (expands into its member skills)
"skills": [
  {
    "source": {
      "type": "CORTEX_EXTENSION",
      "path": "MY_DB.MY_SCHEMA.MY_EXTENSION",
      "version": "VERSION$2"
    }
  }
]
```

## CoCo Desktop Plugins

Plugins bundle skills, MCP servers, hooks, and subagents into a single installable package.

### Plugin Structure

```
my-plugin/
  .cortex-plugin/
    plugin.json         ← Manifest
  skills/
    my-skill/
      SKILL.md          ← Skill definition
  agents/
    my-agent.md         ← Subagent
  .hooks.json           ← Event hooks
  .mcp.json             ← MCP server configs
```

### Plugin Manifest (plugin.json)

```json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "A custom plugin for data analysis",
  "skills": ["skills"],
  "hooks": {},
  "mcpServers": {}
}
```

### Plugin Sources

| Location | Path | Notes |
|----------|------|-------|
| Bundled | Shipped with app | Read-only, opt-in |
| User | `~/.snowflake/cortex/plugins/` | Available across workspaces |
| Project | `.cortex/plugins/` in project | Shared via version control |
| Catalog | Snowflake Cortex Extension | From Plugins Catalog |
| GitHub | Cloned from repo | Syncable |

### Plugins Catalog (Sharing)

```
┌──────────────────────────────────────────────────────────┐
│              PLUGINS CATALOG WORKFLOW                      │
│                                                            │
│  Author                            Consumer                │
│  ──────                            ────────                │
│  Create plugin locally             Browse catalog in       │
│       │                            Snowsight or CoCo       │
│       ▼                                  │                 │
│  Publish to Catalog ──────────────▶ Import via            │
│  (CORTEX EXTENSION                  snow:// URI            │
│   TYPE=PLUGIN)                           │                 │
│       │                                  ▼                 │
│  Grant READ to roles            Plugin appears in          │
│                                 CoCo Desktop               │
└──────────────────────────────────────────────────────────┘
```

## Exam Tips

1. **CoWork URL**: `https://ai.snowflake.com` (standard) or `https://si-<org-acct>.snowflakecomputing.com` (private)
2. **SNOWFLAKE INTELLIGENCE object** manages which agents appear in CoWork (one per account)
3. **ALLOWED_INTERFACES = (SNOWFLAKE_INTELLIGENCE)** restricts user to CoWork only
4. **Skills use SKILL.md** at the root of each skill folder — agent discovers them automatically
5. **Cortex Extensions** bundle multiple skills and are shared via catalog with `READ` privilege
6. **Plugins** are CoCo Desktop packages (skills + MCP + hooks + subagents)
7. **Agent SDK** available in Python and TypeScript — builds agentic apps using same tools as Cortex Code
8. **Deep Research** = multi-step investigation mode (up to 10 min)
9. **Teams integration** reuses CoWork agents — same config works across all interfaces
10. **Automations** = scheduled re-runs of CoWork queries delivered via email
11. **File upload** in CoWork: CSV, DOCX, JSON, PDF, PPTX, TXT, XLSX (up to 50MB, max 5 files)
12. **Plugin catalog** uses `snow://skill_catalog/` or `snow://cortex_extension/` URIs
