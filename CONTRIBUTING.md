## ✅ What to Contribute

### 💚 Encouraged

| Type | Description |
|------|-------------|
| 🐛 **Corrections** | Fix incorrect technical content |
| ❓ **Questions** | Add practice questions with detailed explanations |
| 💻 **Examples** | SQL/Python examples demonstrating exam concepts |
| 📝 **Clarifications** | Fill in missing details for existing topics |
| 🆕 **Updates** | New Snowflake features relevant to the exam |

### 🚫 Not Accepted

| Type | Why |
|------|-----|
| 📋 Verbatim exam dump content | Copyright / ethics violation |
| 🎨 Off-topic material | Must relate to Gen AI certification |
| 💔 Structure-breaking changes | Existing navigation depends on current layout |

---

## 📐 Guidelines

| Rule | Detail |
|------|--------|
| 🎨 **Style** | Match existing files: heading hierarchy, exam tip boxes, code blocks |
| 🔗 **Cross-reference** | Every quiz question answer must exist in the topic notes |
| 💡 **Explanations** | Questions need correct answer + WHY explanation |
| ⚖️ **Distribution** | Respect domain weights: 18% / 38% / 29% / 15% |
| 🌐 **Sources** | Reference official Snowflake docs URLs |
| 🎯 **Focus** | Write for the exam: what you need to answer correctly |

---

## 📤 Pull Requests

```
✅ Good: "Add AUTO_SUSPEND details to 1.2 Cortex Search"
❌ Poor: "update stuff"
```

- Clear title describing the change
- Explain what and why
- Keep PRs focused on one topic
